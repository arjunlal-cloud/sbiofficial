Build an AI Concierge chat widget for [SBI Network].

This is a floating chat assistant that answers questions about the organization — its mission, programs, how to get involved — and redirects off-topic questions back to org content. Here's exactly how to build it, modeled on a working implementation.

Stack assumptions (match what you already have):

React + Vite frontend (same as this project)
Express backend in the same monorepo (or adapt to your backend)
Replit AI Integrations (OpenAI-compatible proxy — no user API key needed)
Step 1 — Backend route

Add a new Express router at POST /api/openai/conversations/:id/messages. The route should:

Initialize an OpenAI client using process.env.AI_INTEGRATIONS_OPENAI_API_KEY as the apiKey and process.env.AI_INTEGRATIONS_OPENAI_BASE_URL as the baseURL. (These are auto-injected by Replit when you add the OpenAI AI Integration.)
Read req.body.content (the user's message) and req.body.history (array of {role, content} — take the last 10 entries).
Call openai.chat.completions.create() with stream: true, model gpt-4o-mini (or whatever model you want), and this message array:
{ role: "system", content: ORG_CONTEXT } — your org system prompt (write this yourself, see Step 1a)
...history (the last 10 turns)
{ role: "user", content: userMessage }
Set response headers Content-Type: text/event-stream, Cache-Control: no-cache, Connection: keep-alive.
For each streamed chunk: write data: ${JSON.stringify({ content: chunkText })}\n\n to the response.
When done: write data: ${JSON.stringify({ done: true })}\n\n and end the response.
On error: write data: ${JSON.stringify({ error: "..." })}\n\n then done: true — never throw to the client.
Step 1a — Write the org system prompt (ORG_CONTEXT)

This is how the concierge stays on-topic. It's a plain string constant in the route file. Include:

One paragraph: who the org is, its mission, and who it serves
Key programs/initiatives with brief descriptions
Any stats or facts the AI should cite
Explicit rules: stay focused on org topics; redirect off-topic questions gently; never fabricate names, dates, or figures not listed; where to send people who want to volunteer or partner
The AI has no other knowledge source — everything it knows about the org comes from this string.

Step 2 — Frontend streaming helper

Create src/lib/aiStream.ts. It should be a function with this signature:

streamAi(url, body, onChunk, signal) => Promise<{ ok: boolean; error?: string }>
Implementation: fetch(url, { method: "POST", headers: { "Content-Type": "application/json" }, body: JSON.stringify(body), signal }), then read the response body as a stream, split on \n, parse each data: {...} line as JSON, call onChunk(parsed.content) for each content chunk, and resolve when parsed.done === true. Return { ok: false, error: parsed.error } if an error frame is received.

Step 3 — UI component

Create src/components/ai/AskOrgWidget.tsx (rename to match your org). Structure:

State: isOpen (bool), messages (array of {role: "user"|"assistant", content: string}), input (string), isStreaming (bool), abortRef (AbortController ref)
Initial greeting: A hardcoded assistant message like "Hi! I'm the [Org] Concierge. Ask me anything about our mission, programs, or how to get involved." — do NOT make an API call for this.
On submit: append the user message + empty assistant message to state, call streamAi() pointing at your backend route (use ${import.meta.env.BASE_URL.replace(/\/$/, "")}/api/openai/conversations/concierge/messages), and in onChunk append each chunk to the last assistant message in state. Set isStreaming false when done.
Layout (fixed positioning):
When closed: render a fixed 64×64px circular button at bottom: 24px, right: 24px, z-index: 50 with a chat icon. Clicking opens the drawer.
When open: render a fixed 350×500px card at bottom: 24px, right: 24px, z-index: 50 with a branded header bar, a scrollable message list, and a text input + send button at the bottom.
User messages right-aligned; assistant messages left-aligned. Show three animated dots while streaming.
Use AnimatePresence + Framer Motion for smooth open/close (or CSS transitions if you don't have Framer Motion).
Mount this component inside your app root so it appears on every page.
Step 4 — Replit AI Integration setup

In your Replit project, go to the Integrations panel and add the OpenAI integration. This auto-injects AI_INTEGRATIONS_OPENAI_API_KEY and AI_INTEGRATIONS_OPENAI_BASE_URL as secrets — you do not need your own OpenAI account or key.

What to customize for your org:

The ORG_CONTEXT system prompt string (the entire org knowledge base lives here)
Widget title ("Ask FOFP" → "Ask SBI" or whatever fits)
Colors/styling to match your design system
The model name if you want something other than gpt-4o-mini
What NOT to do:

Don't add RAG or a vector database for v1 — in-prompt context is sufficient for a single org
Don't expose AI_INTEGRATIONS_OPENAI_API_KEY to the frontend; keep all OpenAI calls server-side
Don't make an API call for the initial greeting — show it as a client-side constant
